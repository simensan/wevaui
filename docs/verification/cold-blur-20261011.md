# Cold paint blur follow-up — October 11, 2026

The shared core's four-channel SSE2 horizontal blur now processes two
independent rows together. It shares index calculation and gives the CPU
independent running sums to execute. Float differences, double accumulation,
edge clamping, radius and rounding are unchanged. Odd-height textures use a
single-row tail. The portable and one-channel kernels are unchanged.

No ABI, CSS, host API or rendering-quality change is involved. This reduces
work in an existing blur path; it does not introduce a global texture cache
or retain document resources after destruction.

## Performance

Paired GCC Release core runs in WSL on the same Ryzen 7 9800X3D, 1280×720.
Each of three pairs creates 40 documents per sample and binary, alternating
before/after order on the middle pair. The baseline executable was saved
before rebuilding. Builds and tests did not overlap these measurements.

| Cold sample | Before, median run mean | After, median run mean |
|---|---:|---:|
| HUD | 51.952 ms | 50.653 ms |
| Glass | 51.869 ms | 51.719 ms |
| Menu | 17.502 ms | 17.407 ms |

HUD's observed reduction is **1.299 ms (2.5%)**. Its median run-best timing
also decreases, from 48.452 to 47.231 ms. This is a modest local improvement:
one HUD pair's mean is slower after the change, and the glass/menu differences
are too small to claim a useful gain. Do not generalize this into a host,
whole-game FPS or lower-end hardware claim. Windows host libraries were
rebuilt and checked, but these timing numbers are from GCC, not MSVC.

Allocation counts and requested bytes are unchanged in all three samples.
The HUD still takes about 50 ms to create in this core-only test. Host asset
loading and rendering are excluded, as is document destruction. Preparing
and reusing screens remains the larger next step for preventing visible hitches.

## Evidence

The complete `check.sh --release` gate passed: 14 GCC suites, 16 Clang
sanitizer suites, 334 Chrome layout captures, 66 browser behavior scripts plus
the existing known IME failure, and the Godot backend/scene/native export checks.
Both Windows host libraries rebuilt without warnings. Unity Native EditMode
passed 242 tests with the same two environment-gated inconclusive tests.

Raw evidence is preserved under `.utmp/cold-opt-20261011/`: paired logs,
`paired-summary.json`, the saved baseline benchmark, build logs, the full gate,
Unity XML, and the inspected core HUD render (`hud.png`). Phase logging before
the change identified the large four-channel background blur as an expensive
part of cold HUD painting; instrumented phase timings are not the reported
before/after benchmark.

`weva_blur_variants` already covers random/transparent/flat textures, odd
dimensions, one-pixel axes, large images and multiple radii. All **192 cases**
retain exact output bytes versus the portable kernel. These are implementation
equivalence checks, not a substitute reference for CSS behavior; the Chrome
oracle remains the browser reference.

See the [verification receipt](cold-blur-20261011.json) for final gate results,
binary hashes and raw artifact hashes. The existing Chrome IME exception and
two environment-gated Unity tests remain qualified as before.
