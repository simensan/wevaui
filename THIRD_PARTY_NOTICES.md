## Native engine (`libweva`, statically linked into every shipped binary)

These are compiled into `weva_core` (the Unity plugin) and `weva_godot` (the
Godot addon), so they travel inside those binaries wherever they go.

| Component | Version | Upstream | License | Text in this repo |
|---|---|---|---|---|
| ICU4C | 78.3 | [unicode-org/icu](https://github.com/unicode-org/icu) | Unicode License V3 | `third_party/icu/LICENSE.txt` |
| Unicode Character Database | 17.0.0 | [unicode.org](https://www.unicode.org/Public/17.0.0/ucd/) | Unicode License V3 | `third_party/unicode/LICENSE.txt` |
| Blink WTF `Decimal` | rev `9596b537e435c5c23d247cb7d9925d81e8f7707e` | Chromium Blink | BSD-3-Clause | `third_party/decimal/LICENSE.txt` |
| ada URL parser | 4.0.0 (rev `b12a893a4580`) | [ada-url/ada](https://github.com/ada-url/ada) | MIT **or** Apache-2.0 | `third_party/ada/LICENSE-MIT`, `LICENSE-APACHE` |

ICU is fetched at build time and verified against a pinned SHA-256; the
Unicode tables are generated by `Tools/generate_graphemes.py`, which checks the
SHA-256 of every UCD input before using it. The two shipped artefacts each
carry these notices with them: the UPM package in its own
`Third Party Notices.md` (generated by `hosts/unity/bundle_notices.py` and
checked in CI), and the Godot addon zip via `hosts/godot/package_addon.py`.

## Package dependencies (fetched via Unity Package Manager — not redistributed)

The package declares Unity first-party dependencies in
`Packages/com.wevaui/package.json` (URP, Input System). These are
downloaded by UPM under their own licenses (Unity Companion License / package
manifests) and are not redistributed in this repository.
