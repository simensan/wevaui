# Unity documentation

Weva builds game UI from HTML/CSS and C# controllers. This **development
preview** requires Unity 6000.3+, URP 17, Input System 1.7 and Windows x64.

## Start here

1. [Getting started](getting-started.md): install, enable rendering and run a page.
2. [Authoring guide](AuthoringGuide.md): connect game state, events, lists and forms.
3. [Troubleshooting](troubleshooting.md): diagnose rendering, assets, bindings and input.
